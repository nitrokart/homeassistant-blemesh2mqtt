Add a device

  1. Put the device in pairing mode. For most bulbs: switch it off and on 3 to 5 times until it blinks or pulses. Check your device manual.
  2. Press Scan and keep the device powered and close to the Home Assistant host (within a few metres) for the whole pairing.
  3. Choose the device, give it a name and press Provision. This can take up to a few minutes. Do not power-cycle the device while it runs.
Only one device can be paired at a time. A device already paired to another app or hub must be factory reset first.

Help and troubleshooting
  • The light does not show up in Home Assistant: check that the MQTT pill above is green, the MQTT integration is set up in Home Assistant, and search the Entities page for the device name.
  • Scan finds nothing: the device must be in pairing mode during the scan. Move it closer to the host and scan again.
  • Pairing fails: factory reset the device, put it in pairing mode right before pressing Provision and try again. Open the log below for the exact reason.
  • Raspberry Pi onboard Bluetooth: set the add-on option io to generic.
  • Removing a device: Remove resets the device and forgets it. If the device is unreachable, use Force remove, then factory reset it manually.
  • Pairing data is stored in the add-on data folder and survives updates. Back it up with your Home Assistant backups.
